# RAG Studio

This repository documents my journey of building a Retrieval-Augmented Generation (RAG) application from scratch.

The aim is to learn and implement modern Generative AI concepts through hands-on development.

## What is RAG?

RAG (Retrieval-Augmented Generation) is a technique that allows AI models to answer questions using information retrieved from custom documents and knowledge sources.

## Project Goals

- Learn how RAG systems work
- Explore document processing and search
- Understand embeddings and vector databases
- Build a chatbot that can answer from uploaded documents
- Gain practical experience with Generative AI

## Who Is This Repository For?

- Beginners interested in AI
- Students and freshers
- Anyone curious about how ChatGPT-like systems are built

No prior knowledge of Python, Machine Learning, or AI is required to follow the project updates.
